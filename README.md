# sorssy — لوحة إدارة مصادر وتطبيقات iOS

لوحة عربية لإدارة بيانات التطبيقات في مصدر iQsign: الاسم، الوصف، التصنيف، الأيقونة، الإصدار، ورابط تنزيل IPA. هذه اللوحة تدير الإدراجات وروابط الملفات؛ لا تعدّل محتويات ملفات IPA نفسها ولا تستضيفها.

## الروابط

- لوحة الإدارة: <https://albyatysjad74-art.github.io/sorssy/>
- ملف السورس: <https://raw.githubusercontent.com/albyatysjad74-art/sorssy/main/iQsign-Apps-Source.json>
- المستودع: <https://github.com/albyatysjad74-art/sorssy>

## طريقة الاستخدام

1. افتح اللوحة واختر المصدر، ثم افتح التطبيق لتعديل بياناته، أو استخدم أزرار إضافة تطبيق/مصدر.
2. عند الإرسال، تفتح صفحة طلب GitHub؛ سجّل الدخول بحساب مالك المستودع `albyatysjad74-art` واضغط **Create issue**.
3. يفحص GitHub Actions البيانات، ثم يحدّث ملف JSON تلقائيًا ويغلق الطلب بعد نجاحه. المصادر الخارجية تظهر للقراءة فقط.
4. نشر GitHub Pages الحالي يتحدث تلقائيًا بعد وصول التغيير إلى الفرع `main`.

لا يوجد رمز دخول أو مفتاح GitHub داخل الموقع العام. يقبل سير العمل الطلب فقط إذا كان منشئ الطلب ومنفذ الحدث حساب المالك نفسه؛ وهذا يمنع شخصًا آخر من تغيير طلب مفتوح باسم المالك.

## بناء وفحص المشروع

الموقع ثابت ولا يحتاج تجميع حزم أو تثبيت مكتبات. ابنِ الحزمة محليًا عبر:

```bash
python3 scripts/build_site.py
```

ينشئ الأمر مجلد `dist/` ويجري فحصًا لملفات JSON وروابط HTTPS وصياغة JavaScript. يتطلب Python 3 وNode.js. كما يشغّل GitHub Actions البناء واختبارات صلاحية المالك عند كل دفع إلى `main` أو فتح طلب دمج، ويحفظ حزمة الموقع كأثر بناء لمدة 14 يومًا.

استخدم روابط HTTPS عامة لملفات IPA والأيقونات التي تملك حق توزيعها؛ الموقع لا يرفع الملفات ولا يخزنها.


## تطبيق iPhone وiPad الأصلي

يوجد تطبيق SwiftUI أصلي داخل `ios/`، وليس واجهة ويب مغلّفة. يحمّل كتالوج المصادر العام وملفات JSON عبر HTTPS، ويعرض البحث والتصنيفات وتفاصيل التطبيقات وروابط التنزيل وسجل الإصدارات. يمكن تعديل أو إضافة إدراجات في المصدر المملوك، أو إضافة رابط مصدر جديد؛ المصادر الخارجية تبقى للقراءة فقط. لا يرفع التطبيق ملفات IPA ولا يغيّر محتوياتها.

حفظ التعديلات يفتح Issue مُعبّأ مسبقاً على GitHub، على نفس نهج لوحة الويب. يجب تأكيد الإرسال بحساب `albyatysjad74-art`؛ لا يُضمّن أي GitHub token أو كلمة مرور داخل التطبيق.

لبناء التطبيق على macOS مع Xcode وXcodeGen:

```bash
brew install xcodegen
./ios/build-unsigned-ipa.sh
```

كما يبني سير GitHub Actions الملف تلقائياً عند تحديث ملفات iOS، ويمكن تشغيله يدوياً من تبويب Actions. يرفع `Sorssy-unsigned.ipa` كأثر بناء لمدة 30 يوماً. الملف الناتج **غير موقّع**؛ لذلك لا يُثبّت مباشرة على iPhone/iPad حتى يُوقّع بشهادة وملف provisioning صالحين لمعرّف الحزمة `app.sorssy.ios`. لا توجد شهادة أو ملف provisioning لهذا التطبيق محفوظان في المستودع.
