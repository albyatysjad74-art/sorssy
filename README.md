# sorssy — مصدر تطبيقات iQsign

ملف المصدر بصيغة JSON: [`iQsign-Apps-Source.json`](./iQsign-Apps-Source.json) — يحتوي التطبيقات التي نُقلت من المصدر السابق، ورابطه المباشر:

`https://raw.githubusercontent.com/albyatysjad74-art/sorssy/main/iQsign-Apps-Source.json`

## إضافة تطبيق

افتح [لوحة sorssy](https://albyatysjad74-art.github.io/sorssy/)، وأدخل اسم التطبيق ومعرّف الحزمة والإصدار ورابط الصورة ورابط تنزيل IPA. بعد الضغط على «إضافة إلى السورس»، راجع الطلب في GitHub واضغط **Create issue**. عندها يتحقق GitHub Actions من البيانات ويضيف التطبيق تلقائيًا إلى ملف المصدر. الإضافة مقصورة على حساب مالك المستودع.

الموقع لا يخزن ملفات IPA أو الصور؛ ارفعها إلى استضافة موثوقة والصق روابط HTTPS المباشرة. لا تضف بيانات دخول أو رموز وصول إلى الموقع أو ملف المصدر.
