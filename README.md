## لوحة الإدارة

افتح [لوحة sorssy](https://albyatysjad74-art.github.io/sorssy/) لعرض المصادر وقوائم التطبيقات. تستطيع إضافة رابط مصدر JSON عام لعرض تطبيقاته للقراءة، وفتح أي تطبيق من مصدر sorssy لتعديل الاسم والوصف والتصنيف والأيقونة والإصدار ورابط التنزيل. المصادر الخارجية للعرض فقط.

بعد حفظ تعديل أو إضافة تطبيق/مصدر، راجع طلب GitHub واضغط **Create issue**؛ GitHub Actions يتحقق من الطلب ويحفظه تلقائيًا. الإضافة والتحرير محصوران بحساب مالك المستودع.

الموقع لا يخزّن ملفات IPA أو الصور ولا يحتوي رموز دخول. استخدم روابط HTTPS عامة للملفات التي تملك حق توزيعها.
